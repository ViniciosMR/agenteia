# Backup não executa

## Sintomas
- O backup não termina
- Aparece erro ao executar o backup
- O backup não foi executado há vários dias
- O destino do backup não está disponível
- O backup falha com mensagem de erro

## Causas comuns
- Disco de destino cheio ou desconectado
- Arquivo em uso impedindo o backup
- Serviço de backup parado
- Senha ou credencial expirada
- Problema de rede (se backup em servidor)

## Solução passo a passo
1. Verifique se o disco de destino do backup está conectado e tem espaço livre.
2. Verifique se o serviço de backup está em execução.
3. Feche arquivos que estão sendo usados e que podem estar impedindo o backup.
4. Verifique as credenciais de acesso ao destino do backup.
5. Execute o backup manualmente para ver a mensagem de erro exata.
6. Verifique se há problema de rede, se o backup for para servidor ou nuvem.
7. Reinicie o computador e tente executar o backup de novo.

## Quando abrir chamado
Se o backup continuar não executando depois de verificar destino, espaço e credenciais, abra um chamado informando o software de backup usado, a mensagem de erro exata e o destino do backup.
