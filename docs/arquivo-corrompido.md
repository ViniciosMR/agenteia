# Arquivo corrompido

## Sintomas
- O arquivo não abre
- Aparece mensagem de erro ao abrir o arquivo
- O arquivo está com tamanho zero ou muito pequeno
- O conteúdo do arquivo está ilegível ou com caracteres estranhos
- O programa fecha ao tentar abrir o arquivo

## Causas comuns
- Desligamento inesperado do computador
- Erro ao salvar o arquivo
- Vírus ou malware
- Problema no disco rígido
- Transferência interrompida (download ou cópia)

## Solução passo a passo
1. Tente abrir o arquivo em outro computador para confirmar se é problema do arquivo ou do computador.
2. Restaure uma versão anterior do arquivo: botão direito no arquivo > Propriedades > Versões anteriores.
3. Verifique se há backup do arquivo em nuvem ou servidor.
4. Use a opção de abrir e reparar do programa (Word, Excel, etc.).
5. Execute a verificação de disco: chkdsk /f /r no Prompt de Comando como administrador.
6. Se o arquivo foi baixado de novo, faça o download novamente.
7. Se for arquivo importante, entre em contato com o suporte para tentar recuperação.

## Quando abrir chamado
Se o arquivo for importante e não puder ser recuperado por versões anteriores ou backup, abra um chamado informando o nome do arquivo, onde ele está localizado e o que aconteceu antes de corromper.
