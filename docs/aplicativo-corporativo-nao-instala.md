# Aplicativo corporativo não instala

## Sintomas
- O aplicativo não instala no celular ou computador
- Aparece erro de instalação
- A instalação trava ou falha no final
- Não consigo baixar o aplicativo da loja
- O aplicativo instala, mas não abre

## Causas comuns
- Espaço insuficiente no dispositivo
- Versão do sistema operacional não suportada
- Restrição de segurança da empresa
- Conexão com internet instável
- Arquivo de instalação corrompido

## Solução passo a passo
1. Verifique se há espaço livre no dispositivo para a instalação.
2. Verifique se o sistema operacional está atualizado e é compatível com o aplicativo.
3. Verifique se a internet está funcionando.
4. Baixe o aplicativo novamente, o arquivo pode ter corrompido.
5. Em computadores corporativos, verifique se tem permissão de administrador para instalar.
6. Se for aplicativo corporativo, entre em contato com o suporte para liberação.
7. Reinicie o dispositivo e tente instalar de novo.

## Quando abrir chamado
Se o aplicativo corporativo não instalar depois de verificar espaço, sistema e internet, abra um chamado informando o nome do aplicativo, o dispositivo e a mensagem de erro exata.
