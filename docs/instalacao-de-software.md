# Instalação de software

## Sintomas
- Preciso de um programa que não está instalado no meu computador
- O instalador pede senha de administrador e eu não tenho
- Aparece a mensagem "Seu administrador bloqueou a execução deste aplicativo"
- Baixei o instalador, mas ele não abre ou não conclui
- Quero instalar uma extensão ou um programa gratuito que vi na internet

## Causas comuns
- Usuários comuns não têm permissão de administrador, por segurança
- O software não é homologado pela área de TI e segurança
- Falta licença para o programa solicitado
- O instalador foi baixado de um site não oficial

## Solução passo a passo
1. **Procure primeiro na Central de Software (ou portal de aplicativos) da empresa.** Ela lista os programas já homologados e permite instalar sem precisar de administrador.
2. **Se o programa não estiver na lista, abra uma solicitação de software** informando: nome e versão do programa, site oficial do fabricante, para que será usado (justificativa de negócio), se o gestor está de acordo e quantas pessoas vão usar.
3. Aguarde a análise de segurança e de licenciamento. O prazo varia conforme a política da empresa.
4. Não tente contornar o bloqueio nem baixar instaladores de sites não oficiais. Isso expõe o computador a vírus e pode gerar problema de licença.
5. Depois da instalação, abra o programa para confirmar que funciona e faça login, se for o caso.

## Quando abrir chamado
- Se o programa é homologado, mas a instalação pela Central de Software falha: informe o nome do programa e a mensagem de erro exata.
- Se precisa de um programa novo: abra a solicitação de software com os dados do passo 2.
