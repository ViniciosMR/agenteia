# Teclado numérico não funciona

## Sintomas
- As teclas do teclado numérico não funcionam
- O Num Lock está ligado, mas as teclas não digitam números
- As teclas numéricas funcionam como setas de navegação
- O teclado numérico não responde
- O teclado numérico funciona só às vezes

## Causas comuns
- Num Lock desativado
- Tecla Shift pressionada (desativa temporariamente o Num Lock)
- Driver do teclado com problema
- Teclado numérico danificado
- Configuração de acessibilidade ativada (Teclas de Filtro)

## Solução passo a passo
1. Pressione a tecla Num Lock para ativar o teclado numérico.
2. Verifique se a tecla Shift não está pressionada.
3. Desative as Teclas de Filtro: Configurações > Acessibilidade > Teclado > desative Teclas de Filtro.
4. Reinicie o computador e teste o teclado numérico.
5. Atualize o driver do teclado no Gerenciador de Dispositivos.
6. Teste outro teclado para confirmar se é problema do teclado ou do computador.
7. Se for notebook, verifique se não há tecla Fn necessária para ativar o numérico.

## Quando abrir chamado
Se o teclado numérico não funcionar depois de ativar Num Lock, desativar Teclas de Filtro e testar outro teclado, abra um chamado informando se é teclado externo ou do notebook e o modelo do computador.
