# Autenticação de dois fatores não funciona

## Sintomas
- Não recebo o código de verificação no celular
- O código não é aceito
- O aplicativo de autenticação não gera códigos
- Perdi o celular com o aplicativo de autenticação
- O código expira antes de eu digitar

## Causas comuns
- Celular sem sinal ou sem internet
- Data e hora do celular incorretas
- Aplicativo de autenticação desatualizado
- Celular perdido ou trocado
- Código digitado errado

## Solução passo a passo
1. Verifique se o celular tem sinal e internet.
2. Confirme se a data e a hora do celular estão corretas e com ajuste automático.
3. Reinicie o aplicativo de autenticação ou o celular.
4. Tente usar um código de backup, se tiver gerado anteriormente.
5. Se trocou de celular, transfira o aplicativo de autenticação para o novo aparelho.
6. Se perdeu o celular, entre em contato com o suporte de TI para redefinir a autenticação.

## Quando abrir chamado
Se não conseguir acessar depois de verificar data/hora, reiniciar o celular e tentar códigos de backup, abra um chamado informando seu nome, matrícula e se perdeu ou trocou de celular.
