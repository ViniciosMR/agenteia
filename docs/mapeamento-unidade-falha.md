# Mapeamento de unidade falha

## Sintomas
- A unidade de rede mapeada não aparece
- Aparece erro ao mapear unidade de rede
- A unidade mapeada fica com um X vermelho
- Não consigo acessar a unidade mapeada
- O mapeamento some depois de reiniciar

## Causas comuns
- Caminho de rede incorreto
- Servidor de arquivos fora do ar
- Senha ou credencial expirada
- Unidade já mapeada com outra letra
- Problema de conexão com a rede

## Solução passo a passo
1. Verifique se a rede está funcionando.
2. Desconecte a unidade mapeada e mapeie de novo: Este Computador > Mapear unidade de rede.
3. Verifique se o caminho de rede está correto (ex: \\servidor\pasta).
4. Marque a opção "Conectar usando credenciais diferentes" se necessário.
5. Verifique se a letra da unidade não está sendo usada por outra unidade.
6. Reinicie o computador e teste o mapeamento de novo.
7. Se o servidor estiver fora do ar, entre em contato com o suporte de TI.

## Quando abrir chamado
Se o mapeamento de unidade falhar depois de verificar caminho, credenciais e rede, abra um chamado informando o caminho de rede, a letra da unidade e a mensagem de erro exata.
