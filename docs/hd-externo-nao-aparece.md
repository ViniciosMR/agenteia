# HD externo não aparece

## Sintomas
- O HD externo não aparece no Explorador de Arquivos
- O HD externo faz barulho de clique
- O HD externo não é detectado pelo computador
- O HD externo aparece, mas não abre
- O HD externo pede para ser formatado

## Causas comuns
- Cabo USB solto ou danificado
- HD externo precisa de mais energia (porta USB não fornece o suficiente)
- Sistema de arquivos corrompido
- HD externo com defeito mecânico
- Letra da unidade em conflito

## Solução passo a passo
1. Verifique se o cabo USB está bem conectado e tente outra porta USB.
2. Se o HD externo tiver fonte própria, verifique se está ligado.
3. Teste o HD externo em outro computador.
4. Verifique no Gerenciamento de Disco (diskmgmt.msc) se o HD aparece e tem letra de unidade.
5. Se não tiver letra, adicione uma letra de unidade.
6. Se o HD fizer barulho de clique, pare de usá-lo imediatamente (pode ser defeito mecânico).
7. Se houver dados importantes e o HD não for detectado, entre em contato com o suporte para recuperação profissional.

## Quando abrir chamado
Se o HD externo não aparecer depois de testar porta, cabo e outro computador, ou se fizer barulho estranho, abra um chamado informando se há dados importantes, o modelo do HD e do computador.
