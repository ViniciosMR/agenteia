# Erro de conexão com banco de dados

## Sintomas
- O sistema não conecta ao banco de dados
- Aparece erro de conexão ao abrir o sistema
- O sistema trava ao salvar dados
- Não consigo acessar informações do banco de dados
- O sistema diz que o servidor não está disponível

## Causas comuns
- Servidor de banco de dados fora do ar
- Problema de rede ou conexão
- Senha do banco de dados alterada
- Serviço de banco de dados parado
- Firewall bloqueando a conexão

## Solução passo a passo
1. Verifique se a rede ou internet está funcionando.
2. Verifique se outros usuários conseguem acessar o sistema (confirma se é problema no servidor).
3. Reinicie o computador e tente acessar o sistema de novo.
4. Verifique se o serviço de banco de dados está em execução no servidor.
5. Verifique se o firewall não está bloqueando a porta do banco de dados.
6. Entre em contato com o suporte do sistema ou TI para verificar o servidor.
7. Anote a mensagem de erro exata para informar ao suporte.

## Quando abrir chamado
Se o erro de conexão com banco de dados persistir e outros usuários também estiverem afetados, abra um chamado imediatamente informando o nome do sistema, a mensagem de erro exata e se é problema geral ou só seu.
