# Falta de espaço em disco

## Sintomas
- Não consigo salvar novos arquivos
- O computador fica lento
- O Windows não atualiza por falta de espaço
- Aparece aviso de disco cheio
- Não consigo instalar programas

## Causas comuns
- Disco rígido pequeno ou quase cheio
- Muitos arquivos pessoais no disco C:
- Backups ocupando muito espaço
- Arquivos de atualização do Windows acumulados
- Pastas de sistema grandes

## Solução passo a passo
1. Verifique quanto espaço livre resta em cada disco no Explorador de Arquivos.
2. Use o Armazenamento do Windows: Configurações > Sistema > Armazenamento para ver o que está ocupando espaço.
3. Exclua arquivos temporários e de atualização do Windows.
4. Mova arquivos pessoais (documentos, fotos, vídeos) para outro disco ou nuvem.
5. Desinstale programas que não usa.
6. Esvazie a lixeira de todos os usuários.
7. Se o disco C: for muito pequeno, considere solicitar upgrade de disco ou SSD.

## Quando abrir chamado
Se não conseguir liberar espaço suficiente ou se o disco C: for muito pequeno para o uso necessário, abra um chamado informando o tamanho total do disco, quanto está livre e o que está ocupando mais espaço.
