# Memória RAM com problema

## Sintomas
- O computador reinicia sozinho
- Aparece tela azul com erros de memória
- O computador fica muito lento
- Programas fecham sozinhos
- O Windows não inicia ou trava durante o uso

## Causas comuns
- Módulo de RAM solto ou com mau contato
- Memória RAM com defeito
- Memória RAM incompatível com a placa-mãe
- Superaquecimento da memória
- Placa-mãe com problema nos slots de memória

## Solução passo a passo
1. Reinicie o computador e veja se o problema persiste.
2. Execute o Diagnóstico de Memória do Windows: busque "Diagnóstico de Memória do Windows" no Iniciar e reinicie para executar.
3. Se o computador for desktop, um técnico pode reencaixar os módulos de memória.
4. Se houver mais de um módulo de memória, teste um de cada vez para identificar o com defeito.
5. Verifique se a memória é compatível com a placa-mãe.
6. Se o diagnóstico encontrar erros, a memória precisa ser substituída.

## Quando abrir chamado
Se o diagnóstico de memória encontrar erros ou se o computador continuar com problemas de reinicialização e tela azul, abra um chamado informando o modelo do computador, a quantidade de RAM e o resultado do diagnóstico.
