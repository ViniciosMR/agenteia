# Mouse não funciona

## Sintomas
- O cursor do mouse não se move
- O mouse não clica
- O cursor pula ou se move estranho
- O mouse sem fio não responde
- O touchpad do notebook não funciona

## Causas comuns
- Mouse desconectado ou sem pilha
- Driver do mouse com problema
- Sensor do mouse sujo
- Touchpad desativado por tecla de atalho
- Conflito com outro dispositivo de apontamento

## Solução passo a passo
1. Verifique se o mouse está conectado ou se tem pilha/bateria.
2. Teste o mouse em outra porta USB ou em outro computador.
3. Limpe o sensor do mouse com um pano seco.
4. Se for mouse sem fio, reconecte o receptor USB ou pareie de novo via Bluetooth.
5. Se for touchpad do notebook, verifique se não foi desativado por tecla de atalho (geralmente Fn + tecla com ícone de touchpad).
6. Atualize ou reinstale o driver do mouse no Gerenciador de Dispositivos.
7. Use o teclado para navegar (Tab, setas, Enter) enquanto resolve o problema.

## Quando abrir chamado
Se o mouse não funcionar depois de verificar conexão, pilhas e testar em outra porta, abra um chamado informando se é mouse com fio, sem fio ou touchpad, e o modelo do computador.
