# Computador reinicia sozinho

## Sintomas
- O computador desliga e liga sozinho
- Aparece tela azul antes de reiniciar
- O computador reinicia durante o uso
- O computador reinicia ao abrir um programa específico
- O computador fica em loop de reinicialização

## Causas comuns
- Superaquecimento do processador
- Problema na fonte de alimentação
- Atualização do Windows pendente
- Driver com problema
- Memória RAM com defeito

## Solução passo a passo
1. Verifique se o computador está superaquecendo: ouça o ventilador e veja se está muito quente.
2. Limpe as saídas de ar do computador com ar comprimido.
3. Verifique se há atualizações do Windows pendentes e instale-as.
4. Desative a reinicialização automática: no Gerenciador de Tarefas, veja se há erro antes do reinício.
5. Atualize os drivers, especialmente de vídeo e placa-mãe.
6. Teste a memória RAM com o Diagnóstico de Memória do Windows.
7. Se o problema continuar, pode ser problema de hardware (fonte ou placa-mãe).

## Quando abrir chamado
Se o computador continuar reiniciando sozinho depois de limpar poeira, atualizar Windows e drivers, abra um chamado informando o modelo, se aparece tela azul e o que estava fazendo quando reiniciou.
