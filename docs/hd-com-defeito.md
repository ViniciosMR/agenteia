# HD com defeito

## Sintomas
- O computador está muito lento
- Aparece erro de leitura/gravação em disco
- Arquivos desaparecem ou ficam corrompidos
- O computador reinicia ou trava ao acessar arquivos
- O disco faz barulho estranho (cliques, arranhões)

## Causas comuns
- Setores defeituosos no disco
- Disco rígido velho ou desgastado
- Queda ou impacto no computador
- Desligamento inesperado (falta de energia)
- Problema no cabo ou conexão do disco

## Solução passo a passo
1. Faça backup dos dados importantes imediatamente, se ainda conseguir acessá-los.
2. Execute a verificação de disco: Prompt de Comando como administrador > chkdsk /f /r.
3. Se o disco fizer barulho de clique, desligue o computador imediatamente para evitar danos maiores.
4. Verifique as conexões do disco (cabo SATA e energia).
5. Teste o disco em outro computador, se possível.
6. Se o disco estiver com defeito, entre em contato com o suporte para substituição e recuperação de dados.

## Quando abrir chamado
Se o HD estiver com defeito, fazendo barulho estranho ou com erros de leitura/gravação, abra um chamado imediatamente informando se há dados importantes, o modelo do computador e o tipo de barulho ou erro.
