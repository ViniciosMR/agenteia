# Restauração de arquivos

## Sintomas
- Preciso recuperar um arquivo excluído
- Preciso restaurar uma versão anterior de um arquivo
- O arquivo foi sobrescrito por engano
- Preciso recuperar dados de um backup
- O arquivo sumiu da pasta

## Causas comuns
- Arquivo excluído por engano
- Arquivo sobrescrito por outra versão
- Falha ao salvar o arquivo
- Problema de sincronização da nuvem
- Arquivo movido para outra pasta sem querer

## Solução passo a passo
1. Verifique a Lixeira: se o arquivo estiver lá, clique com o botão direito > Restaurar.
2. Use o Histórico de Arquivos: clique com o botão direito na pasta > Propriedades > Versões anteriores.
3. Verifique se o arquivo está no OneDrive, Google Drive ou outra nuvem.
4. Verifique se há backup em servidor ou HD externo.
5. Use a busca do Windows para localizar o arquivo (pode ter sido movido).
6. Se o arquivo foi excluído de um servidor de rede, entre em contato com o suporte para restauração do backup.
7. Não salve novos arquivos no mesmo local se precisar de recuperação de dados.

## Quando abrir chamado
Se o arquivo não estiver na Lixeira, não houver versão anterior e for importante, abra um chamado informando o nome do arquivo, a pasta original e quando foi excluído ou modificado pela última vez.
