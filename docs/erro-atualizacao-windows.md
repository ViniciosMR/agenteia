# Erro de atualização do Windows

## Sintomas
- A atualização do Windows não instala
- Aparece código de erro na atualização
- O computador reinicia, mas a atualização não conclui
- A atualização fica travada em uma porcentagem
- O Windows desfaz as alterações depois de reiniciar

## Causas comuns
- Espaço insuficiente em disco
- Internet instável durante o download
- Arquivos de atualização corrompidos
- Serviço de atualização parado
- Antivírus bloqueando a atualização

## Solução passo a passo
1. Verifique se há espaço livre em disco (pelo menos 20 GB).
2. Reinicie o computador e tente atualizar de novo.
3. Execute o Solucionador de Problemas do Windows Update: Configurações > Atualização e Segurança > Solucionar problemas.
4. Pare o serviço de atualização, renomeie a pasta SoftwareDistribution e reinicie o serviço.
5. Desative temporariamente o antivírus e tente atualizar.
6. Use a ferramenta de criação de mídia do Windows para fazer a atualização manual.
7. Redefina os componentes do Windows Update pelo Prompt de Comando como administrador.

## Quando abrir chamado
Se a atualização continuar com erro depois de liberar espaço, executar o solucionador e redefinir componentes, abra um chamado informando o código de erro exato e a versão do Windows.
