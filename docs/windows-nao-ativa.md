# Windows não ativa

## Sintomas
- Aparece mensagem "Windows não está ativado"
- Não consigo personalizar o Windows (fundo de tela, cores)
- Aparece marca d'água "Ative o Windows"
- O Windows diz que a chave do produto é inválida
- A ativação falha com código de erro

## Causas comuns
- Chave do produto inválida ou já usada
- Mudança de hardware (placa-mãe)
- Servidores de ativação fora
- Versão do Windows não corresponde à chave
- Problema de licença corporativa

## Solução passo a passo
1. Verifique se a internet está funcionando (necessário para ativação).
2. Vá em Configurações > Atualização e Segurança > Ativação e clique em "Solucionar problemas".
3. Digite a chave do produto novamente, se tiver uma.
4. Se mudou o hardware recentemente, use a opção "Alterei o hardware recentemente".
5. Em ambiente corporativo, entre em contato com o suporte de TI para ativação por volume.
6. Reinicie o computador após a ativação.

## Quando abrir chamado
Se o Windows não ativar depois de usar o solucionador de problemas e verificar a chave, abra um chamado informando o código de erro, se mudou algum hardware recentemente e se é computador corporativo.
