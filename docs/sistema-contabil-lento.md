# Sistema contábil lento

## Sintomas
- O sistema contábil demora para abrir
- Os relatórios demoram para gerar
- O sistema trava ao salvar lançamentos
- A navegação entre telas é lenta
- O sistema fecha sozinho com muitos dados

## Causas comuns
- Banco de dados grande ou fragmentado
- Servidor lento ou sobrecarregado
- Muitos usuários acessando ao mesmo tempo
- Computador com pouca memória RAM
- Versão desatualizada do sistema

## Solução passo a passo
1. Feche outros programas para liberar memória.
2. Reinicie o computador e abra só o sistema contábil.
3. Verifique se outros usuários também estão com lentidão (problema no servidor).
4. Atualize o sistema contábil para a versão mais recente.
5. Limpe o cache do sistema, se houver essa opção.
6. Gere relatórios em horários de menor movimento.
7. Se o problema for no servidor, entre em contato com o suporte do sistema ou TI.

## Quando abrir chamado
Se o sistema contábil continuar lento depois de reiniciar e fechar outros programas, abra um chamado informando o nome do sistema, se acontece com todos os usuários e o que estava fazendo quando ficou lento.
