# Programa não abre

## Sintomas
- Clico no programa e nada acontece
- O programa começa a abrir e fecha sozinho
- Aparece mensagem de erro ao abrir o programa
- O programa trava na tela de carregamento
- O ícone do programa não responde

## Causas comuns
- Programa corrompido
- Conflito com outro programa ou antivírus
- Versão desatualizada
- Permissões insuficientes
- Arquivo de instalação incompleto

## Solução passo a passo
1. Reinicie o computador e tente abrir o programa de novo.
2. Feche o programa pelo Gerenciador de Tarefas, se estiver travado.
3. Execute o programa como administrador (botão direito > Executar como administrador).
4. Desative temporariamente o antivírus e teste.
5. Atualize o programa para a versão mais recente.
6. Desinstale e reinstale o programa.
7. Verifique se o programa é compatível com a versão do Windows.

## Quando abrir chamado
Se o programa continuar não abrindo depois de reiniciar, executar como administrador e reinstalar, abra um chamado informando o nome do programa, a versão e a mensagem de erro exata.
