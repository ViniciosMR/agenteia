# Navegador muito lento

## Sintomas
- O navegador demora para abrir
- As páginas demoram para carregar
- O navegador fica sem responder
- Muitas abas abertas deixam o computador lento
- O navegador consome muita memória

## Causas comuns
- Muitas abas abertas ao mesmo tempo
- Muitas extensões instaladas
- Cache e histórico acumulados
- Navegador desatualizado
- Computador com pouca memória RAM

## Solução passo a passo
1. Feche abas que não estão sendo usadas.
2. Desative ou remova extensões que não usa: Menu > Extensões.
3. Limpe o cache e o histórico: Configurações > Privacidade e segurança > Limpar dados de navegação.
4. Atualize o navegador para a versão mais recente.
5. Reinicie o navegador e o computador.
6. Teste em modo de navegação anônima para ver se melhora.
7. Se o computador tiver pouca RAM, considere fechar outros programas.

## Quando abrir chamado
Se o navegador continuar lento depois de fechar abas, remover extensões e limpar cache, abra um chamado informando o navegador, a versão e se acontece em todos os sites ou só alguns.
