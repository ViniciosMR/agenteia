# Excel muito lento

## Sintomas
- O Excel demora para abrir arquivos
- O Excel trava ao salvar ou calcular
- O computador fica lento com o Excel aberto
- O Excel fecha sozinho com arquivos grandes
- As fórmulas demoram para calcular

## Causas comuns
- Arquivo muito grande ou com muitas fórmulas
- Muitos complementos instalados
- Arquivo em rede ou OneDrive com conexão lenta
- Pouca memória RAM
- Versão desatualizada do Excel

## Solução passo a passo
1. Feche outros programas para liberar memória.
2. Verifique se o arquivo está salvo localmente, não em rede ou OneDrive.
3. Desative complementos: Arquivo > Opções > Complementos > Ir para Complementos do Excel > desmarque os desnecessários.
4. Salve o arquivo em formato binário (.xlsb) para reduzir o tamanho.
5. Divida arquivos muito grandes em vários arquivos menores.
6. Atualize o Office para a versão mais recente.
7. Reinicie o computador e abra o Excel de novo.

## Quando abrir chamado
Se o Excel continuar lento depois de desativar complementos, salvar localmente e atualizar, abra um chamado informando o tamanho do arquivo, se acontece com todos os arquivos ou só um, e a quantidade de RAM do computador.
