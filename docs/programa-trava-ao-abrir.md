# Programa trava ao abrir

## Sintomas
- O programa abre, mas fica sem responder
- O computador fica lento ao abrir o programa
- O programa fecha sozinho depois de abrir
- Aparece mensagem "Não está respondendo"
- O programa trava o computador inteiro

## Causas comuns
- Pouca memória RAM disponível
- Arquivo do programa corrompido
- Conflito com outro programa aberto
- Versão desatualizada do programa
- Problema de driver de vídeo

## Solução passo a passo
1. Feche outros programas que não estão sendo usados para liberar memória.
2. Reinicie o computador e abra só o programa problemático.
3. Atualize o programa para a versão mais recente.
4. Atualize os drivers de vídeo.
5. Verifique se há atualizações do Windows pendentes.
6. Desinstale e reinstale o programa.
7. Teste abrir o programa em outro computador para confirmar se é problema do arquivo ou do computador.

## Quando abrir chamado
Se o programa continuar travando depois de fechar outros programas, atualizar e reinstalar, abra um chamado informando o nome do programa, o que estava fazendo quando travou e se acontece em outros computadores.
