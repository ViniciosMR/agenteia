# Ransomware

## Sintomas
- Arquivos não abrem e têm extensão estranha
- Aparece mensagem exigindo pagamento para liberar arquivos
- A área de trabalho foi alterada com aviso de resgate
- Não consigo acessar pastas e arquivos importantes
- O computador está bloqueado com mensagem de resgate

## Causas comuns
- Anexos de e-mail suspeitos abertos
- Download de software de fontes não confiáveis
- Falha de segurança no sistema
- Senha fraca ou comprometida
- Falta de backup dos arquivos

## Solução passo a passo
1. Desconecte imediatamente o computador da rede (Wi-Fi e cabo de rede).
2. NÃO pague o resgate: não há garantia de recuperação dos arquivos.
3. Tire uma foto ou print da mensagem de resgate para o chamado.
4. Identifique quais arquivos e pastas foram afetados.
5. Verifique se há backup dos arquivos em nuvem ou servidor.
6. Entre em contato com o suporte de TI imediatamente.
7. Não tente remover o ransomware sozinho, para não destruir evidências.

## Quando abrir chamado
Abra um chamado IMEDIATAMENTE se suspeitar de ransomware. Informe o que a mensagem diz, quais arquivos estão afetados, se há backup e quando o problema começou.
