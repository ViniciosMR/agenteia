# Software ERP não abre

## Sintomas
- O sistema ERP não inicia
- Aparece erro de conexão ao abrir o ERP
- O ERP trava na tela de login
- O ERP fecha sozinho ao abrir um módulo
- Não consigo acessar o sistema ERP

## Causas comuns
- Servidor do ERP fora do ar
- Problema de conexão com o banco de dados
- Versão do cliente ERP desatualizada
- Usuário sem permissão no sistema
- Antivírus bloqueando o ERP

## Solução passo a passo
1. Verifique se a internet ou a rede local está funcionando.
2. Verifique se outros colegas conseguem acessar o ERP (confirma se é problema geral ou só seu).
3. Reinicie o computador e tente abrir o ERP de novo.
4. Verifique se o cliente ERP está na versão mais recente.
5. Desative temporariamente o antivírus e teste.
6. Verifique se seu usuário tem permissão para acessar o ERP.
7. Anote a mensagem de erro exata para informar ao suporte.

## Quando abrir chamado
Se o ERP não abrir depois de verificar rede, reiniciar e testar com outros colegas, abra um chamado informando o módulo do ERP, a mensagem de erro exata e se outros colegas também estão com problema.
