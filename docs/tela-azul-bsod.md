# Tela azul (BSOD)

## Sintomas
- Aparece tela azul com mensagem de erro
- O computador reinicia depois da tela azul
- Aparece código de erro na tela azul
- O computador trava e mostra tela azul
- A tela azul aparece ao abrir um programa específico

## Causas comuns
- Driver com problema ou desatualizado
- Memória RAM com defeito
- Problema no disco rígido
- Conflito de software
- Atualização do Windows com problema

## Solução passo a passo
1. Anote o código de erro ou a mensagem da tela azul (ex: CRITICAL_PROCESS_DIED, IRQL_NOT_LESS_OR_EQUAL).
2. Reinicie o computador e veja se o problema volta.
3. Desinstale programas ou drivers instalados recentemente.
4. Atualize os drivers no Gerenciador de Dispositivos.
5. Execute a verificação de disco: abra o Prompt de Comando como administrador e digite chkdsk /f /r.
6. Execute o Diagnóstico de Memória do Windows.
7. Se o problema persistir, restaure o Windows para um ponto anterior.

## Quando abrir chamado
Se a tela azul continuar aparecendo, abra um chamado informando o código de erro exato, o que estava fazendo quando apareceu e se começou depois de instalar algum programa ou driver.
