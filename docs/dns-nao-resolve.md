# DNS não resolve

## Sintomas
- Não consigo acessar sites pelo nome (ex: www.google.com)
- Posso acessar sites pelo endereço IP, mas não pelo nome
- Aparece erro "Servidor DNS não encontrado"
- A internet funciona de forma intermitente
- Alguns sites abrem, outros não

## Causas comuns
- Servidor DNS configurado incorretamente
- Servidor DNS fora do ar
- Problema de conexão com a internet
- Cache DNS corrompido
- Configuração de rede incorreta

## Solução passo a passo
1. Verifique se a internet está funcionando.
2. Limpe o cache DNS: Prompt de Comando como administrador > ipconfig /flushdns.
3. Altere o DNS para um público (ex: 8.8.8.8 e 8.8.4.4 do Google) nas configurações de rede.
4. Reinicie o computador e o roteador.
5. Teste acessar sites em outro dispositivo para confirmar se é problema geral.
6. Verifique as configurações de DNS no roteador, se aplicável.
7. Entre em contato com o suporte de TI se o problema persistir.

## Quando abrir chamado
Se o DNS não resolver depois de limpar cache, alterar DNS e reiniciar, abra um chamado informando quais sites não abrem, se acontece em todos os dispositivos e a mensagem de erro exata.
