# USB não reconhecido

## Sintomas
- O dispositivo USB não aparece ao conectar
- Aparece mensagem "Dispositivo USB não reconhecido"
- O dispositivo USB não funciona depois de conectar
- O computador não lê pen drive ou HD externo
- O dispositivo USB conecta e desconecta sozinho

## Causas comuns
- Porta USB com problema
- Driver do dispositivo desatualizado
- Dispositivo USB com defeito
- Configuração de economia de energia desligando a porta USB
- Sistema de arquivos do dispositivo não suportado

## Solução passo a passo
1. Conecte o dispositivo USB em outra porta USB do computador.
2. Teste o dispositivo em outro computador para confirmar se funciona.
3. Reinicie o computador com o dispositivo conectado.
4. Atualize o driver do dispositivo no Gerenciador de Dispositivos.
5. Desative a economia de energia das portas USB: Gerenciador de Dispositivos > Controladores de barramento serial universal > Propriedades > Gerenciamento de energia > desmarque "Permitir que o computador desligue este dispositivo".
6. Verifique se o dispositivo não precisa de energia externa (HD externo pode precisar de cabo Y ou fonte própria).
7. Formate o dispositivo se o sistema de arquivos não for suportado (atenção: apaga todos os dados).

## Quando abrir chamado
Se o USB não for reconhecido depois de testar outra porta, outro computador e atualizar driver, abra um chamado informando o tipo de dispositivo, o modelo do computador e se o dispositivo funciona em outro computador.
