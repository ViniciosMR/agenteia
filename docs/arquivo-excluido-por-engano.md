# Arquivo excluído por engano

## Sintomas
- O arquivo não está mais na pasta
- Excluí o arquivo sem querer
- O arquivo sumiu depois de salvar
- Não consigo encontrar um arquivo importante
- Excluí a pasta errada

## Causas comuns
- Exclusão acidental pelo usuário
- Arquivo movido para outra pasta sem querer
- Programa excluiu o arquivo automaticamente
- Sincronização da nuvem excluiu o arquivo
- Vírus ou malware excluiu o arquivo

## Solução passo a passo
1. Verifique a Lixeira: clique com o botão direito no arquivo > Restaurar.
2. Use a busca do Windows (tecla Windows) para procurar o arquivo pelo nome.
3. Verifique se o arquivo foi movido para outra pasta.
4. Verifique o Histórico de Arquivos ou Versões anteriores da pasta.
5. Se o arquivo estava no OneDrive ou Google Drive, verifique a lixeira da nuvem.
6. Se o arquivo estava em servidor de rede, entre em contato com o suporte para restauração do backup.
7. Não instale programas ou salve arquivos no mesmo disco se precisar de recuperação avançada.

## Quando abrir chamado
Se o arquivo não estiver na Lixeira, não for encontrado pela busca e não houver backup, abra um chamado informando o nome do arquivo, a pasta original e quando foi excluído.
