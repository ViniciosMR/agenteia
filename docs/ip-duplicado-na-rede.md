# IP duplicado na rede

## Sintomas
- Aparece mensagem de erro "Endereço IP duplicado"
- A internet não funciona no computador
- Outros computadores na rede também perdem a conexão
- A conexão de rede cai e volta sozinha
- Não consigo acessar pastas ou impressoras de rede

## Causas comuns
- Dois dispositivos com o mesmo IP estático
- Servidor DHCP não funcionando corretamente
- Computador com IP fixo conflitando com outro
- Problema no roteador ou servidor DHCP

## Solução passo a passo
1. Reinicie o computador para obter um novo IP via DHCP.
2. Reinicie o roteador para renovar os endereços IP da rede.
3. Verifique se o computador está configurado para obter IP automaticamente (DHCP).
4. Se o computador tem IP fixo, altere para automático ou escolha um IP fora do intervalo usado.
5. Desconecte e reconecte o cabo de rede ou o Wi-Fi.
6. Se o problema persistir em vários computadores, o servidor DHCP pode estar com problema.

## Quando abrir chamado
Se o erro de IP duplicado persistir depois de reiniciar o computador e o roteador, ou se afetar vários computadores, abra um chamado informando o modelo do computador, a mensagem de erro exata e se outros computadores também estão afetados.
