# Lixeira esvaziada

## Sintomas
- Esvaziei a lixeira e preciso de um arquivo de volta
- O arquivo foi excluído permanentemente
- Não consigo encontrar o arquivo depois de esvaziar a lixeira
- Preciso recuperar dados excluídos permanentemente

## Causas comuns
- Lixeira esvaziada acidentalmente
- Arquivo excluído com Shift+Delete (exclusão permanente)
- Lixeira configurada para esvaziar automaticamente
- Arquivo excluído de unidade de rede (não vai para a lixeira)

## Solução passo a passo
1. Verifique se há backup do arquivo em nuvem (OneDrive, Google Drive) ou servidor.
2. Verifique o Histórico de Arquivos ou Versões anteriores da pasta original.
3. Se o arquivo estava em servidor de rede, entre em contato com o suporte para restauração do backup.
4. Não salve novos arquivos ou instale programas no disco onde o arquivo estava, para não sobrescrever os dados.
5. Entre em contato com o suporte de TI o mais rápido possível para tentar recuperação de dados.
6. Forneça o nome exato do arquivo e a pasta onde estava.

## Quando abrir chamado
Abra um chamado imediatamente se precisar recuperar arquivo excluído permanentemente. Informe o nome do arquivo, a pasta original, quando foi excluído e se há backup em nuvem ou servidor.
